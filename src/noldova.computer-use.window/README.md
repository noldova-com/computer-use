# @noldova/computer-use.window

The computer use module's window part: the status bar item that shows while a session controls the screen, and its stop command.

It exports the window part's class, `ComputerUseWindowPart`, which builds with Noldova Desktop's own window classes from `@noldova/desktop.window`; its `src/api/index.d.ts` documents it.
The module's own package, [`@noldova/computer-use`](https://github.com/noldova-com/computer-use/tree/main/src/noldova.computer-use), gives it to the app's window and pins it at its own version.
[documents/ARCHITECTURE.md](https://github.com/noldova-com/computer-use/blob/main/documents/ARCHITECTURE.md) says how it is built, and the [README](https://github.com/noldova-com/computer-use#readme) how to build and test it.
